How to add a site

Quickest way: open the site, click the toolbar icon and use Pick thumbnail. Then hover a thumbnail until its preview plays and click the expand button. Usually that's all it takes.

  1. Thumbnails. Right-click a thumbnail, choose Inspect, and find the box that is the size of the thumbnail image (not a text link). Write a CSS selector for it. If class names end in a random-looking hash, match the stable start, e.g. [class*='VideoCard__thumb']. If an attribute ends in a number, match the start, e.g. [data-id^='SPW_'].
  2. Preview (optional). By default the extension enlarges whichever video is playing over the thumbnail. If it picks the wrong thing, turn on Debug mode, hover a thumbnail until its preview plays, and press Alt+Shift+P with the mouse over it. That saves the preview selector for you.
  3. Save. Open pages update straight away.

The site has to play previews when you hover its thumbnails; this enlarges that preview, so it never opens the video's page.
