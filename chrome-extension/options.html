How to add a site

Quickest way: open the site, click the toolbar icon and use Pick thumbnail, then open a video and use Pick player. Check this page shows what the rule matches, and suggests fixes. To do it by hand:

  1. Open the site, right-click a video thumbnail and choose Inspect.
  2. Find the box that is the size of the thumbnail image (not a text link) and write a CSS selector for it. If class names end in a random-looking hash, match the stable start, e.g. [class*='VideoCard__thumb'], and use :has() to require a video link inside, e.g. div:has(> a[href*='/video/']).
  3. If the video link isn't found automatically, set Link selector. It's looked for inside the thumbnail first, then in the elements around it.
  4. Pick a Playback mode:
    • Page (try this first): loads the video's own page full-window and hides everything but the player. Inspect the player on a video page and set Player selector to the element holding the video and its controls (YouTube: #movie_player). Some sites, like Dailymotion, refuse to be shown this way.
    • Embed: uses the site's embeddable player. Set a Video ID pattern whose first group captures the ID from the link (for /video/x8abc12: /video/([A-Za-z0-9]+)) and an Embed URL with {id} where the ID goes.
  5. Save, then reload the site.

"Video unavailable" in embed mode means the site refuses embeds on its own pages (YouTube does this). Switch that site to page mode.
